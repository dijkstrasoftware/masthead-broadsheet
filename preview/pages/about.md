Broadsheet is set in a serif for the headlines and a serif for the body, because
that is how a newspaper is set, and hairlines do the rest of the work.

## Corrections

We print them. All of them, at the same size as the original error, which is the
only policy that has ever meant anything.

> A newspaper is a device for making the ignorant more ignorant and the crazy
> crazier — unless somebody bothers to edit it.

## Getting in touch

Write to the desk. Someone reads everything, eventually.
